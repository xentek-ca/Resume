## About this repository

| File | Purpose |

The site is published with GitHub Pages from the root of `main`.

**To update the resume:** edit `index.html` and commit. The live page refreshes within a minute or two.

**To regenerate the PDF:**

1. Open the live page in Chrome and click **Save as PDF**.
2. Set paper to Letter and margins to Default. Turn off **Headers and footers** and turn on **Background graphics**.
3. Save it as `Mukesh-Sharma-Resume.pdf` and upload it here, replacing the old file.

**Keep it public-safe:** this repository is public, so leave out phone numbers, client names and the name of any employer covered by an NDA.
